# voting-rights-prefecture-heatmap

都道府県別の議決権行使状況を可視化するためのHTMLツールです。
総会における議決権行使状況を、都道府県別のヒートマップとして確認できます。

## 概要

このツールでは、各都道府県の議決権総数と行使数をもとに、行使率を自動計算します。
行使率はヒートマップ形式で表示され、70%を基準として色分けされます。

## 主な機能

* 都道府県別の議決権総数をプリセット
* 行使数の入力による行使率の自動計算
* 都道府県別ヒートマップ表示
* 全国行使率、総議決権数、総行使数の表示
* 特別決議成立までの残り票数表示
* 集計時点の入力
* CSV出力
* 公開用HTMLの生成
* 議決権行使ページ等へのリンク表示

## 使い方

1. `index.html` をブラウザで開く
2. 集計時点を入力する
3. 各都道府県の行使数を入力する
4. ヒートマップと集計結果を確認する
5. 必要に応じてCSV出力または公開HTMLを生成する

## 配色ルール

* 70%未満：暖色系
* 70%以上：寒色系

## 注意

このツールは、総会運営時の状況把握および記録保管を目的とした簡易ツールです。
最終的な議決権行使数や決議成立の判断は、公式な集計結果に基づいて確認してください。
